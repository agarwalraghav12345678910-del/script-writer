# Reference Reels — Forensic Analysis Protocol & Swipe File

## Why Reference Reels Matter

Reading about viral reels is different from dissecting them.

When a creator gives you a transcript of a reel they love, they're telling you something more valuable than any MCQ answer: they're showing you their taste, their aspirational voice, and the emotional response they want to create in their audience.

Your job is to reverse-engineer exactly why that reel worked — and extract the structural DNA to replicate in every script you write for this creator.

---

## Forensic Analysis Protocol

When a creator pastes a transcript, run this full analysis before writing anything else.

### Step 1 — Segment Mapping

Divide the transcript into labelled segments:

```
[SEGMENT: HOOK] — Lines 1-X
[SEGMENT: SETUP] — Lines X-X
[SEGMENT: RE-HOOK] — Line X
[SEGMENT: BREAKDOWN] — Lines X-X
[SEGMENT: PAYOFF] — Line X
[SEGMENT: CTA] — Lines X-X
```

Note: not all reels have all segments. Some skip setup. Some have multiple re-hooks. Map what's actually there — don't force a structure.

### Step 2 — Hook Deep Dive

Answer all of these:

- **Exact words of the hook:** [quote]
- **Hook type:** (shocking fact / bold claim / provocative question / story open / relatability / exclusivity / contrast / pattern interrupt)
- **Psychological trigger activated:** (curiosity gap / pattern interrupt / relatability / threat/loss / social proof / contrarian tension)
- **Open loop created:** What question does it plant in the viewer's mind?
- **Word count:** How many words in the hook?
- **Specificity level:** Does it use specific numbers, names, or details?
- **Promise made:** What does the hook promise the rest of the script will deliver?
- **Why it works:** 2-3 sentences of genuine psychological analysis

### Step 3 — Re-hook Analysis

- **Position:** At what point in the script does the re-hook appear? (seconds or line number)
- **Re-hook type:** (pivot question / escalation / reframe / callback setup / pace change / direct address)
- **Exact words:** [quote]
- **Why it works:** How does it reset the viewer's decision to keep watching?

### Step 4 — Body Structure

- **Number of distinct points or beats:**
- **Average sentence length:** (count words per sentence, average them)
- **Pace:** Fast / Medium / Slow / Variable
- **POV:** First person (I/my) / Second person (you/your) / Third person (they/their) / Mixed
- **Vocabulary level:** Simple (anyone) / Conversational / Technical / Mixed
- **Power words used:** List any emotionally charged words
- **Emotional arc:** What emotion does the viewer feel in the first half vs second half?

### Step 5 — CTA Deep Dive

- **Exact words of the CTA:** [quote]
- **CTA type:** (save / follow / share / combination / curiosity / provocative)
- **Does it feel earned?** Yes / No / Partially — and why
- **Specificity:** Does it tell viewers exactly what they're getting?
- **Length:** Word count
- **Natural delivery:** Does it sound like the creator is still talking, or did they switch into "ask mode"?
- **What works:** Why this CTA converts
- **What would improve it:** Honest critique

### Step 6 — Language Fingerprint

- **Signature phrases:** Any phrases that feel distinctive or ownable
- **Sentence rhythm:** Mostly short / Mostly long / Variable / Triple rhythm / Question-answer pairs
- **Filler words:** Any "like", "um", "basically", "literally" used stylistically vs accidentally
- **Tone words:** 3 adjectives that describe the overall voice
- **What to steal:** Specific language patterns worth replicating

### Step 7 — Viral Verdict

- **Why this reel likely performed well:** 3-4 sentences of genuine analysis
- **The single most important thing to replicate:** One structural or linguistic element
- **What to avoid:** Anything that felt forced, weak, or inconsistent with the rest

## Cross-Reel Pattern Recognition

After 3+ reels are analysed, build a Niche Viral Blueprint.

### Blueprint Structure

```
NICHE VIRAL BLUEPRINT
Created from: [X] reference reels
Last updated: [date]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

UNIVERSAL PATTERNS (appears in ALL reels):
✓ [Pattern 1]
✓ [Pattern 2]
✓ [Pattern 3]

COMMON PATTERNS (appears in 50%+ of reels):
~ [Pattern 1]
~ [Pattern 2]

OCCASIONAL PATTERNS (appears in 1-2 reels):
◦ [Pattern 1]

PATTERNS TO AVOID (weak or inconsistent):
✗ [Pattern 1]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

HOOK DNA:
Most common hook type: [type]
Average hook length: [X] words
Key ingredient: [what every hook has]

RE-HOOK DNA:
Average position: [X] seconds
Most common type: [type]
Key phrase pattern: [example]

BODY DNA:
Average sentence length: [X] words
Dominant POV: [first/second/third]
Information density: [fast/medium/slow]
Points per reel: [X]

CTA DNA:
Most common type: [save/follow/share/combo]
Average length: [X] words
Tone: [natural/transactional/provocative]

PAYOFF DNA:
Average length: [X] words
Common structure: [e.g., contrast pair / single bold statement]
Emotional note: [what the viewer feels at the payoff]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

NICHE VIRAL STRUCTURE:
[Hook type] → [Setup type] → [Re-hook type] → [Body structure] → [Payoff structure] → [CTA type]
```

### How to Use the Blueprint

Every new script must be mapped to this blueprint before delivery.

Before writing, answer:
1. Does this script's hook match the dominant hook DNA?
2. Is the re-hook placed at the right position?
3. Does the sentence length match the body DNA?
4. Does the CTA match the creator's preferred type?
5. Is the payoff as short and quotable as the blueprint's payoff DNA suggests?

If any answer is no — adjust before delivering.

## Notes on Transcript Quality

If the creator provides a partial transcript or rough notes rather than a full word-for-word transcript:

- Work with what you have — partial analysis is better than none
- Flag which sections you couldn't analyse and why
- Ask the creator to fill in gaps if they remember specific lines
- Focus extra attention on hook and CTA since these are most impactful

If no transcript is available for a reel they love:
- Ask them to describe: the first line, how it ended, one moment that stood out
- This partial data still informs creator preference even without full forensics
